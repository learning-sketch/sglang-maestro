# 算子层 Agent · 两个 Agent 对抗，并为 RL 预留接口 · 演说词

## 主张（约 20 秒）

这一页讲算子层的下一步：把现在的一个 Agent，拆成两个互相对抗的 Agent。

因为现在提出修改的和认为修改有效的是同一个，没人专门找它的漏洞。

## 两方各做什么（约 30 秒）

左边提议者，和原来的策略推演一样，读规格、读黑板、读调优经验，产出补丁。变化是它还要给一句明确主张：这个补丁在哪些形状下快多少。

右边挑战者是新角色，读补丁和历史反例，专找边界形状、非对齐、精度陷阱，产出反例用例。

## 谁判决（约 25 秒）

一条底线：挑战者没有裁决权，它只提交用例。两方用例进同一套确定性 Harness，交叉编译、对精度、真机测速、四道门判决，一个模型都不参与。

所以这不是两个模型互相打分，原来最硬的那条性质一点没松。

## 怎么收敛（约 20 秒）

一个回合四步：提议者采 N 个候选，挑战者提交反例，Harness 逐个判决，取最优。

终止条件写死了：预算内找不到新反例，且四道门全过，才晋升候选。每个反例进回归集，这套系统越跑越难骗。

## RL 预留（约 50 秒）

底下这条虚线泳道是 RL 预留，虚线表示本阶段不做训练循环。

关键是中间这行：一次对抗回合本身就是一次 rollout。同一份规格采 N 个候选、逐个判决、组内取最优，这就是 GRPO 的一个 group，只是今天 N 等于 1。

所以不需要为了以后能训练而重构。四个缝已经留好：策略接口换基座、分组采样调大 N、奖励函数把判决折成标量、轨迹记录每组落盘。训练循环是右边那个灰框，是独立系统，就位后读这份轨迹即可。

## 防作弊（约 25 秒）

最后这行红字：强化学习做代码生成，最大的风险是模型学会骗测速。

我们有别人没有的东西——物理下界。奖励被 roofline 上界封顶，再加 CPU 参考和多形状标准用例，刷不出假收益。这是前面那套下界核算在这里的第二个用处。


## 压缩版（约 45 秒，赶时间时只讲这四句）

算子层的下一步是把一个 Agent 拆成两个：提议者造补丁并给出主张，挑战者造反例。

判决权不在任何一个模型手里，两方的用例跑同一套确定性 Harness，四道门一票否决。

底下这条虚线是 RL 预留。一次对抗回合就是一次 rollout，今天 N 等于 1，接口缝已经留好，训练循环就位后直接读轨迹，架构不用改。

奖励被物理下界封顶，这是我们敢做强化学习而不怕刷分的底气。


## 预计会被问到

**挑战者是不是也要用大模型？**

先不用。找边界形状、非对齐、断崖，大部分可以是规则加搜索，便宜且可复现。模型只用来补规则想不到的那部分。

**两个模型会不会合谋？**

合谋的前提是它们能互相认可成绩。这里不能——认可权在 Harness，判决是编译、精度、真机测速。

**预算指什么？**

按回合数和编译次数计，这个数还没定。

**现在做到哪一步了？**

对抗和 RL 都还没实现，这页是下一步设计。已经实现的是右边这套 Harness 和四道门。
